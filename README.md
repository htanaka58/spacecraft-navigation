# Autonomous Spacecraft Navigation

A 2D spacecraft navigation simulator built with Python, Gymnasium,
Stable-Baselines3, NumPy, and Pygame.

## Project goals

The spacecraft agent will learn to:

- Reach a target waypoint
- Avoid obstacles
- Minimize fuel consumption
- Follow natural-language mission goals
